only as Org Babel blocks here; no parallel =.mmd= or =.typ= source is allowed.

** Audit Boundary

The current proof binds these Rust implementation surfaces:

- =xiuxian-vector/src/store.rs=: metadata predicates borrow values from the
  parsed JSON tree instead of cloning each matched value.
- =xiuxian-vector/src/ops/observability.rs=: five independent table probes run
  in one =tokio::try_join!= round.
- =xiuxian-db-store/src/valkey/client.rs=: key enumeration uses cursor-based
  =SCAN= pages rather than the server-blocking =KEYS= command.
- =xiuxian-qianji-control/src/valkey_hot_state.rs=: independent snapshot reads
  execute concurrently and scan results are duplicate-safe.

The proof does not claim end-to-end production speedup. It proves local cost
dominance under explicit assumptions; benchmarks and Ubuntu CI remain the
runtime acceptance surfaces.

= WAS modernization cost model

Let $q$ be candidate count, $m$ metadata predicates, $b$ mean serialized value
bytes, $r$ independent storage reads, $l$ mean read latency, $n$ keyspace size,
and $p$ the cursor page size.

$ C_("clone") = q dot m dot b $

$ C_("borrow") = 0 $

$ L_("serial") = r dot l $

$ L_("parallel") = max(l_1, dots, l_r) <= sum_(i=1)^r l_i $

$ W_("KEYS") = n $

$ W_("SCAN-step") = min(p, n) <= p $

$ O_("Org") = "ASP" != "Wendao" $

The optimized architecture removes metadata clone bytes, reduces independent
read critical-path rounds from five to one, and bounds each Valkey enumeration
step by the configured page size. Cursor results must be deduplicated because
incremental scans may repeat keys while the keyspace changes. Org query and
agent-memory ownership remains in ASP, preventing a second read-model cost and
authority surface in Wendao.
#+end_src

** Lean Obligations

The executable package proves:

1. the legacy model violates the hot-path policy;
2. the modern model satisfies zero-copy, single-round, non-blocking, and
   duplicate-safe invariants;
3. borrowed metadata contributes zero clone bytes;
4. positive clone dimensions have positive allocation cost;
5. one concurrent read round never exceeds five serial equal-latency rounds;
6. each scan step is page-bounded while blocking key enumeration has no fixed
   work bound;
7. ASP, rather than Wendao, owns the Org authority boundary.
